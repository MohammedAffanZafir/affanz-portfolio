# Mohammed Affan Zafir — Animated Slideshow Portfolio

A polished, responsive portfolio website with full-screen slide navigation, subtle motion design, interactive project-detail modals, keyboard and touch navigation, a mobile-friendly menu, and a dedicated Certificates slide.

## Files
- `index.html` — page content and sections
- `style.css` — theme, responsive layout, and animations
- `script.js` — slideshow navigation and project modals
- Certificates slide — AWS Cloud Practitioner, AWS Generative AI learning, Python internship, C++ OOP SDP, Embedded AI workshop, Salesforce training track, and Agent Hack participation
- `Affan_Zafir_Resume.pdf` — add your current resume PDF here (optional, for the download button)

## Run locally
Open `index.html` in a modern browser.

## Publish on GitHub Pages
1. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the root of your repository.
2. Upload your actual PDF into the same root folder and name it exactly `Affan_Zafir_Resume.pdf`.
3. In **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/(root)`, and save.
4. Wait for deployment, then open the GitHub Pages URL.

## Interaction
- Click the top navigation or bottom dots to slide between sections.
- Use the arrow buttons, keyboard ←/→, Page Up/Page Down, or swipe left/right on touch screens.
- Click a project card to open its detail modal.
- The resume button downloads `./Affan_Zafir_Resume.pdf`.

## Before publishing
- Confirm the resume filename and path exactly match.
- Update any project descriptions, verified metrics, and credential status as appropriate.
- Keep contact details and links you want publicly visible.
